# DPDPA Suite

An early-stage, hosted developer platform and AI toolkit that helps healthcare providers and other sensitive-data businesses comply with India's Digital Personal Data Protection Act, 2023 and the DPDP Rules, 2025.

This repository currently holds the public announcement page (`index.html`).

## Hosting on GitHub Pages

The site is a single static HTML file with no build step.

1. Push this repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. The site will be live at `https://<your-username>.github.io/dpdpa-suite/` within a minute or two.

## Local preview

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 8000
```

then visit http://localhost:8000.
